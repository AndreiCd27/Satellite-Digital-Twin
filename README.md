
# Satellite Digital Twin (C++/OpenGL/PyTorch)

Goal: Given an satellite image at high pixel-to-meter resolution, classify buildings and reconstruct an entire 3D urban scene
Libraries: 
* C++ libs: OpenGL (version 4.3), GLFW, GLM, ImGui, TinyTIFF, stbimage, pybind
* Python libs: pytorch, numpy, rasterio, shapely, mapbox_earcut
